# Site editing rules

- Never use middle-dot separators in visible text, titles, metadata, HTML entities, or CSS-generated content. Use natural wording or whitespace between separate items.
- Do not add eyebrows, kickers, or label lines above headings or titles.
- Do not number sections unless Joakim asks.
- Make titles descriptive and self-explanatory; do not add subtitles that simply repeat them.
- New test files, test-only helpers, and fixtures require explicit approval. Prefer existing checks and direct browser or runtime verification.
